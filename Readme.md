# Personal Information Manager

## Project Description
This is my first Python project. It is a simple Personal Information Manager that stores and displays personal information.

## Features
- Stores name, age, city, and hobby.
- Takes favorite food as user input.
- Takes favorite color as user input.
- Checks for empty input.
- Calculates age in months.
- Displays information in a formatted way.
- Shows welcome and goodbye messages.
