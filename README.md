Student Grade Calculator

1. Project Overview

The Student Grade Calculator is a Python project developed for The Developers Arena Week 2 internship task. It calculates student averages, assigns grades, and provides comments based on marks.

2. Project Objectives

- Calculate average marks of students.
- Assign grades using if/elif/else statements.
- Store student results using lists and dictionaries.
- Calculate class average, highest average, and lowest average.
- Validate user inputs and handle errors.
- Search for students by name.
- Save results to a file.

3. Setup Instructions

1. Install Python 3 from https://www.python.org/

2. Create a project folder named week2-grade-calculator.

3. Create the file grade_calculator.py.

4. Copy the Python program into the file.

5. Open a terminal in the project folder.

6. Run the program using:
   
   "python grade_calculator.py"

7. Enter the number of students, their names, and subject marks.

6. Technical Details

The project uses:

- Variables to store student information.
- Functions to calculate grades and validate marks.
- Conditional statements to assign grades.
- For loops to process multiple students.
- While loops to validate inputs.
- Lists and dictionaries to store results.
- Try-except blocks to handle invalid inputs.
- File handling to save student results.
